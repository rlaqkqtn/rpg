# 신의 은총 (가제) — 2D 플랫포머 프로토타입

할로우 나이트/메이플스토리 스타일을 참고한 **실제 캔버스 기반 2D 액션 플랫포머**입니다.
빌드 도구 없이 `game/index.html`을 브라우저로 열면 바로 실행됩니다. (GitHub Pages에 `game/` 폴더째 올려도 동작합니다.)

> 이전 버전(메뉴 선택식 텍스트 프로토타입)에서 전면 재설계했습니다.

## 조작

- 이동: ← → 또는 A / D
- 점프: Space 또는 ↑ / W
- 직업 슬롯 전환: 1 / 2 / 3
- 스킬 사용: Z / X / C (현재 활성 슬롯 직업의 스킬 1·2·3)

## 구현된 시스템

- **실제 물리 기반 플랫포머**: 중력, 점프, 좌우 이동, 발판 충돌 판정
- **14개 방으로 이루어진 맵**: 지역별 던전 4방(입구·중간·비밀·심층) × 3지역 + 중앙 신전 허브 + 최종보스 아레나
  - 방마다 화면 하나(스크롤 없음), 가장자리의 문/포탈로 다른 방과 연결
  - 비밀 방은 발판 사이 정밀 점프가 필요한 독립 구역으로, 그 지역 히든 직업 3개가 전부 배치되어 있음
- **미니맵**: 세계 전체 삼각형 개요 + 현재 던전의 방 연결 그래프(탐험한 방만 표시)
- **실시간 전투**: 근접 히트박스 / 원거리 투사체, 스킬 타입별(딜·버프·제어·디버프·유틸) 쿨타임과 효과
  - 천상=원거리, 지하=근접(암귀사냥꾼 예외), 지상=도발 위주 테마를 스킬의 range 속성으로 반영
- **적 AI**: 근접 패트롤형, 원거리 저격형, 최종보스(패턴 혼합)
- **직업 슬롯 = 보유 파편(키) 개수에 비례** (1→2→3), 같은 직업을 여러 슬롯에 중복 장착 불가(자동 스왑 처리)
- **순차 개방 이동**: 신전에서 첫 파편 이후 남은 두 지역 중 하나를 선택, 완료 시 마지막 지역 자동 개방. 스폰 지역은 언제든 되돌아갈 수 있음
- **낙하 서사 기반 랜덤 스폰** + 최종 엔딩(왕족 반전 암시)

## 파일 구성

```
game/
  index.html      # 진입점
  style.css        # UI 스타일
  js/
    data.js        # 직업 데이터 (일반 9 + 히든 9)
    world.js        # 방(room) 맵 데이터 - 발판/문/적/픽업 배치
    engine.js        # 물리 · 전투 · 상태 관리 로직
    render.js        # 캔버스 드로잉 · HUD · 미니맵 · 모달
README.md
```

## ⚠️ 이번 프로토타입에서 임시로 채운 부분

- **전투 수치**: 피해량, 쿨타임, 방어막량 등은 전부 임시 밸런스 (예: 딜 스킬 쿨타임 0.5초, 데미지 14~22 등). 특히 오류인간의 "캡 브레이크"는 3초간 전 스킬 쿨타임을 사실상 제거하는 방식으로 단순 구현
- **쉬었음청년의 스킬 융합/진화 UI**: 설계상 별도 스킬창에서 조합·진화를 선택하는 구조인데, 이번 프로토타입에서는 다른 히든 직업처럼 고정 스킬 3개로 단순화됨 (실제 조합 시스템 미구현)
- **집(제3의 거점)**: 로드아웃 편집용 안전지대는 아직 맵에 포함하지 않음 — 지금은 슬롯 배치를 아무 때나 할 수 있도록 임시 처리
- **던전 방 4개(입구/중간/비밀/심층) 구성 및 지형**: 실제 레벨 디자인이 아니라 시스템 검증을 위한 임시 배치 (발판 위치, 적 배치, 몹 수치 전부 재조정 필요)
- **몬스터/보스 이름과 수치**: 임시 명칭·수치, 실제 밸런싱 필요
- **아트**: 실제 스프라이트 없이 단색 사각형/원으로 표시 (플레이스홀더). 지역별 배경 그라디언트와 장식 파티클(별/먼지/풀빛)만 최소한으로 구분
- **전직(2차 직업) 시스템**: 데이터에는 존재하지만 이번 프로토타입 전투에는 미반영 (기본 스킬 3개만 사용 가능)
